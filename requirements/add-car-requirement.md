# Вимога: додавання автомобіля до Garage

## Початковий стан

- Користувач відкрив QAuto.
- Доступний вхід через `Guest log in`.

## Сценарій

1. Увійти через `Guest log in`.
2. Відкрити Garage і форму `Add car`.
3. У полі Brand обрати `Audi`.
4. У полі Model обрати `TT`.
5. У полі Mileage ввести `12000`.
6. Зберегти форму.

## Очікуваний результат

- Після збереження відкрито Garage.
- URL відповідає сторінці Garage.
- У Garage відображається автомобіль `Audi TT`.

## Межі

- Перевіряється один UI-сценарій у Chromium.
- Вхід у гостьовий профіль є підготовкою до головної перевірки.
- Model залежить від Brand.
- Точні HTML-атрибути й CSS-класи не задані.
- Ознаки UI-елементів треба підтвердити за поточним інтерфейсом.
- Якщо інтерфейс або результат відрізняється від вимоги, треба зафіксувати blocker, а не вигадувати успішний результат.

## Візуальний приклад

`requirements/add-car.png` ілюструє функціональність додавання автомобіля. Скріншот не задає тестові дані чи додаткові очікування для сценарію.
